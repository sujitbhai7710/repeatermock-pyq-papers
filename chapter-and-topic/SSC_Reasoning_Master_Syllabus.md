# SSC Reasoning Master Syllabus
## SSC CGL + CHSL + CPO + MTS + GD — Complete PYQ Classification & Preparation Taxonomy

> **Purpose:** This file is designed not only as a study syllabus but as a **machine-friendly taxonomy for classifying SSC PYQs** from CGL, CHSL, CPO, MTS and GD.
>
> The goal is to make an AI agent able to assign each question to the **most specific primary topic**, with optional secondary tags, while still having a safe **MISC / OTHER POSSIBLE** bucket for questions that do not fit neatly into a standard chapter.

# 61. PRIMARY VS SECONDARY TOPIC RULE FOR AI

A single PYQ may genuinely involve multiple reasoning concepts.

## 61.1 Primary Topic

Choose the topic representing the **main operation required to solve the question**.

Example:

> Four people are sitting in a circle. A is second to the left of B...

Primary:
- `CIRCULAR_SEATING`

Secondary:
- `DIRECTION`
- `ORDER_POSITION`

Do NOT make `DIRECTION` primary merely because left/right appears in the wording.

---

## 61.2 Example: Coding + Series

If the question presents:

> A coded pattern converts CAT → DBU and asks for the code of DOG.

Primary:
- `CODING_DECODING`

Secondary:
- `ALPHABET_POSITION`

If it presents a long sequence generated by a repeated letter transformation:
- Primary may be `ALPHABET_SERIES`
- Secondary: `CODING_DECODING`

---

## 61.3 Example: Missing Number + Arithmetic

If the question gives:

> 4, 9, 16, 25, ?

Primary:
- `NUMBER_SERIES`

Secondary:
- `SQUARE_PATTERN`

Not `MISSING_NUMBER_MATRIX`, unless it is visually structured as a matrix/diagram.

---

## 61.4 Example: Mirror + Rotation

If the question asks which image is the mirror image of the given figure:

Primary:
- `MIRROR_IMAGE`

Even if the answer options contain rotated versions.

---

## 61.5 Example: Blood Relation + Ranking

If the question first establishes family relationships and then asks:

> Who is the youngest?

Primary:
- Usually `BLOOD_RELATION` if family structure is the central challenge

Secondary:
- `AGE_COMPARISON`

If the family relation is trivial and the real task is determining age order:
- Primary: `AGE_REASONING`
- Secondary: `BLOOD_RELATION`

---

# 62. HOW TO HANDLE PYQ WORDING VARIATIONS

Do NOT classify purely from keywords.

For example:

- "second to the left" does not automatically mean `DIRECTION`
- "between" does not automatically mean `RANKING`
- "number" does not automatically mean `NUMBER_SERIES`
- "letters" does not automatically mean `ALPHABET_TEST`
- "statement" does not automatically mean `STATEMENT_CONCLUSION`
- "figure" does not automatically mean `NON_VERBAL`

Instead ask:

> **What transformation, relationship, deduction or visual operation must the solver perform?**

# 73. IMPORTANT OVERLAP RULES

## Series vs Coding
If each term is independently transformed → likely `CODING_DECODING`.
If sequence positions determine the pattern → likely `SERIES`.

## Number Series vs Missing Number
A row/sequence → `NUMBER_SERIES`.
A diagram/matrix with one or more empty positions → `MISSING_NUMBER` or `NUMBER_MATRIX`.

## Direction vs Seating
If the central task is movement/final direction → `DIRECTION_SENSE`.
If the central task is arranging people → `SEATING`.

## Syllogism vs Venn
If categorical statements and conclusions → `SYLLOGISM`.
If direct set/category relationship or counting → `VENN_DIAGRAM`.

## Ranking vs Puzzle
If straightforward position ordering → `RANKING_ORDER`.
If many conditional clues must be solved → `PUZZLE` or `ARRANGEMENT`.

## Figure Series vs Pattern Completion
Sequential multiple figures → `NONVERBAL_SERIES`.
One missing section in one figure → `FIGURE_COMPLETION`.

## Mirror vs Rotation
Reflection across mirror axis → `MIRROR_IMAGE`.
Figure turned around its centre → `FIGURE_ROTATION`.

## Cube vs Dice
Numbered/symbol faces on a small object with orientation comparisons → `DICE`.
Painted/cut larger cube or cube counting → `CUBE`.

# 77. IMPORTANT IMPLEMENTATION NOTE

For a PYQ-classification AI, the best architecture is:

```text
PYQ
 ↓
Detect exam metadata
 ↓
Detect verbal / analytical / numerical / visual
 ↓
Detect question mechanism
 ↓
Assign primary topic
 ↓
Assign optional secondary topics
 ↓
Assign subtype/mechanism
 ↓
Check ambiguity
 ↓
Assign confidence
 ↓
Store original question unchanged
```

Do **not** make the AI rewrite the PYQ before classification.

Keep:

```json
{
  "question_original": "...",
  "question_cleaned": "...",
  "exam": "CHSL",
  "year": 2024,
  "primary_topic": "CODING_DECODING",
  "secondary_topics": ["ALPHABET_TEST"],
  "subtype": "LETTER_SHIFT",
  "confidence": 0.95
}
```

This makes later analysis possible by:

- Exam
- Year
- Shift
- Topic
- Subtopic
- Mechanism
- Difficulty
- Frequency
- Repeated concepts
- Cross-exam trends
- PYQ similarity
- Topic-wise question banks
