# SSC GK/GS MASTER SYLLABUS — CGL, CHSL, CPO, MTS, GD

**Purpose:** Master taxonomy for mapping SSC previous-year questions (PYQs) from **SSC CGL, CHSL, CPO, MTS and GD** to the most appropriate subject/topic/subtopic.

**Important scope note:** SSC official notifications use broad General Awareness/General Studies headings rather than an exhaustive finite list of every possible micro-topic. This file therefore contains:
1. The broad areas explicitly used by SSC,
2. A highly granular preparation taxonomy,
3. Cross-topic and miscellaneous categories,
4. An **OTHER / EDGE-CASE / POSSIBLE QUESTION** section so an AI mapper can classify questions that do not fit perfectly into the standard buckets.

## Exam labels

- `CGL` = SSC Combined Graduate Level
- `CHSL` = SSC Combined Higher Secondary (10+2) Level
- `CPO` = SSC Sub-Inspector in Delhi Police and Central Armed Police Forces
- `MTS` = SSC Multi-Tasking (Non-Technical) Staff
- `GD` = SSC Constable (General Duty)

## Suggested machine-readable hierarchy

`EXAM -> DOMAIN -> SUBJECT -> TOPIC -> SUBTOPIC -> MICROTOPIC`

Example:

`CPO -> POLITY -> PARLIAMENT -> BILLS -> MONEY BILL`

If a question can reasonably belong to two areas, prefer the **most specific knowledge tested by the question**, and retain a secondary tag when useful.

# 107. PYQ CLASSIFICATION RULES FOR AN AI AGENT

These rules are recommended for assigning each question to the taxonomy.

## 107.1 Primary classification rule

Assign the question to the **lowest-level topic that directly supplies the answer**.

Example:
- Question: "Article 32 is related to what?"
- Primary: `POLITY -> FUNDAMENTAL RIGHTS -> CONSTITUTIONAL REMEDIES`

Not simply: `POLITY`.

## 107.2 History classification

Use:
- Ancient
- Medieval
- Modern
- Post-Independence

Do not place modern freedom-movement questions under generic current affairs merely because the person/event is famous today.

## 107.3 Culture classification

If the question asks:
- dance → `ART & CULTURE -> DANCE`
- instrument → `ART & CULTURE -> MUSIC -> INSTRUMENTS`
- monument style → `ART & CULTURE -> ARCHITECTURE`
- festival → `ART & CULTURE -> FESTIVALS`

If it asks when/under which ruler a monument was built, historical context may be a secondary tag.

## 107.4 Geography vs Environment

- River/soil/mountain/location → usually Geography
- Species/protected area/conservation/pollution → usually Environment
- A national park question can have both Geography and Environment tags.

## 107.5 Economy vs Current Affairs

- Definition of repo/GDP/inflation → Economy
- "RBI recently changed repo rate to X" → Current Affairs + Economy

## 107.6 Polity vs Current Affairs

- Definition of Article 356 → Polity
- "President's Rule imposed in State X in YEAR" → Current Affairs + Polity

## 107.7 Science vs Science Current Affairs

- "What is photosynthesis?" → Biology
- "New vaccine developed by institution X" → Current Affairs + Biology/Science

## 107.8 Sports vs Sports Current Affairs

- Number of players in hockey → Sports Static GK
- Winner of recent hockey tournament → Current Affairs -> Sports

## 107.9 Static GK vs Current Affairs

Use Static GK when the fact is stable.

Use Current Affairs when the fact depends on time, recent events, newly appointed people, recent awards, recent reports, newly launched schemes, newly added sites, etc.

## 107.10 Current office-holders

Always create a time stamp/version for office-holder questions.

Example:

`POLITY -> PRESIDENT -> CURRENT OFFICE HOLDER -> YYYY-MM`

## 107.11 Ambiguous questions

Store:

- `primary_domain`
- `primary_topic`
- `secondary_domain`
- `secondary_topic`
- `confidence`
- `reason`

Recommended confidence values:

- `HIGH`
- `MEDIUM`
- `LOW`

## 107.12 Unknown / Other

Never force an unknown question into an incorrect category.

Use:

`OTHER -> EDGE_CASE -> <short description>`

Then optionally assign a secondary tag after human/AI review.

# 114. AI CLASSIFIER FALLBACK PRIORITY

When more than one category appears plausible, use this order:

1. **Exact microtopic**
2. **Exact subtopic**
3. **Exact topic**
4. **Subject-level category**
5. **Cross-domain secondary tag**
6. **OTHER / EDGE CASES**

Never discard a useful secondary relationship.

Example:

`Question about a new Ramsar site in India`

Primary:
`CURRENT AFFAIRS -> ENVIRONMENT -> RAMSAR SITES`

Secondary:
`ENVIRONMENT -> WETLANDS`
`GEOGRAPHY -> LAKES/WETLANDS`

# 115. FINAL COVERAGE PRINCIPLE

For practical SSC PYQ mapping, the agent should recognize that the same factual object can occur in multiple contexts.

Example: **Kaziranga** can be:

- Geography → Assam
- Environment → National Park
- Wildlife → One-horned rhinoceros
- Current Affairs → newly designated/updated conservation status
- Static GK → famous national park
- UNESCO → World Heritage Site

The classifier should choose the **context actually tested by the question**, not merely the object named in the question.
